📱 HelpPhone — «Что делать сейчас?»

Android-приложение с пошаговыми инструкциями по самым частым проблемам смартфона.
Отвечаешь на один вопрос «да / нет» — и получаешь готовый алгоритм решения.
Тёмный неоновый интерфейс в стиле «системного терминала».

list	question	solution

✨ Возможности

	•	20 готовых сценариев: батарея, перегрев, память, Wi‑Fi, звук, Bluetooth, камера, микрофон, USB, пароль и другие
	•	Диагностика в один вопрос: ответ «да / нет» ведёт к нужному решению
	•	Поиск по названию и описанию проблемы
	•	Избранное ⭐ — сохрани частые проблемы
	•	Журнал диагностики 📋 — история решённых проблем
	•	Кнопка «Открыть настройки»: сразу открывает нужный раздел (Wi‑Fi, Bluetooth, звук, экран, батарея и т.д.)
	•	Вибро‑отклик при нажатиях и плавные анимации переходов

🧩 Примеры проблем

Телефон быстро разряжается · Сильно нагрелся · Память заполнена · Не работает Wi‑Fi ·
Пропал звук · Завис · Камера выдаёт ошибку · Bluetooth не видит наушники ·
Не работает микрофон · Не подключается к ПК по USB · Забыл пароль экрана · Постоянно вылезает реклама

📥 Установка

	1.	Откройте раздел Releases и скачайте файл HelpPhone-v1.0.apk
	2.	Откройте файл на телефоне Android
	3.	При запросе разрешите установку из этого источника
	4.	Запустите приложение HelpPhone

Требуется Android 7.0 (API 24) или новее.

🛠 Технологии

	•	Kotlin
	•	Jetpack Compose + Material 3
	•	Android SDK (minSdk 24, targetSdk 35)
	•	Gradle (Kotlin DSL)
