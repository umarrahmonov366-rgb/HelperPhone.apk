# 📱 HelpPhone (Что делать сейчас?)

Приложение для быстрой технической помощи и решения частых проблем со смартфоном.

## 🚀 Особенности
- Написано на **Kotlin** с использованием **Jetpack Compose**
- Простой и понятный интерфейс
- Пошаговые инструкции по устранению неполадок

## 🛠 Технологии
- Android SDK
- Kotlin
- Jetpack Compose
